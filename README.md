
# TechMood Data Analytics Bootcamp

## About the Bootcamp
This repository documents my learning journey in the TechMood Data Analytics Bootcamp. It serves as a central portfolio for practical exercises, assignments, and projects developed throughout the program.

## Bootcamp Objectives
- Develop practical data analysis skills.
- Learn how to collect, clean, organize, and analyze data.
- Build meaningful reports and interactive dashboards.
- Improve problem-solving and analytical thinking.
- Apply data analysis tools to real-world scenarios.

## Skills to Learn
- Data Collection and Data Entry
- Data Cleaning and Preparation
- Data Analysis and Interpretation
- Data Visualization and Reporting
- Database Management
- Version Control and Collaboration

## Tools and Technologies
- Microsoft Excel
- SQL
- Python
- Git
- GitHub
- Data Visualization Tools
